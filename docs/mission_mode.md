# 比赛任务模式（GC-BASE-0.3.53 设计）

## 为什么要改固件

Pi 侧线性任务执行器（`pi/robot/mission/`）已能离线跑完两批流程。实车执行需要底盘导航、机构取放、底盘微调在同一启动会话里反复交替，而 0.3.52 固件有三处限制：

1. 机构保持期间只接受配置10和1～5mm/3°微调目标（`base_port.c` Command 的 `MechPort_Holding()` 分支）。
2. 每次交接返回（71 op4）都会 `Start_Init`，下一次底盘动作必须再按 PC0；比赛只允许一键启动一次。
3. 路线目标只接受编译进固件的冻结段（`FrozenIndex`）；自主规划的路线无法下发。

## 改动

| 项 | 内容 |
| --- | --- |
| 配置11 | 任务模式。路线档跟踪参数与 version9 相同（100RPM 上限），沿用 PC1 选区与 PC0 准备/绑定。 |
| 一次启动 | PC0 在本 boot/session 内对配置11只触发一次；交接返回时保留已触发票据，后续 ARM 不再要求按键。会话、boot 变化或 STOP 仍作废。 |
| 规划段 | 配置11目标按 `Exec_Preview` 同一包络逐段校验：kind 1～6、线速≤0.30m/s、线加速≤0.25、线加加速≤0.8、角速≤1.2rad/s、单段参考≤25s、期限30000ms、动作号严格递增。 |
| 偏离保护 | 规划段按参考轨迹逐点监督：位置偏离>6cm或航向偏离>0.15rad停车（与冻结路线 raw 分支同档），总位移与航向变化另设上限。 |
| 微调 | 配置11下接受与配置10逐字节相同的微调模板（期限10000ms），执行前切换跟踪器到微调档，完成后切回路线档。 |
| 运输保持 | 交接合同新增 kind=2（运输保持）：机构两轴、三舵机保持合同姿态，允许配置11、规划段和微调；kind=1 的原微调合同行为不变。 |

不改：250ms 反馈过期、500ms 心跳、超时停车、机构保持核对（`MechPort_HoldCheck`）、故障锁存、PWM/零点人工流程。

## Pi 侧执行顺序（每次导航）

1. 机构执行运输姿态联调表并静止 → 71 op1/op2 提交 kind=2 合同。
2. 首次：配置11 → PC0 准备（选区绑定）→ 等待按键触发。之后跳过。
3. ARM → 逐段下发规划段（或冻结兜底段）→ 等待 COMPLETE。
4. 需要时在同一保持内下发微调。
5. 71 op4 返回；底盘保持 OBSERVING、里程计连续，机构恢复可动作。

## 验证计划

- C 夹具：配置11一次 PC0 后两次交接往返不再要求按键；kind=1 合同仍拒绝配置11；规划段越界、动作号回退、偏离6cm均停车；微调与规划段交替时跟踪参数切换正确。
- Pi 离线：模拟机器人跑通整轮；MissionLink 对固件模型跑一轮“导航→取放→导航”。
- 实车：先空载单段导航+一次交接往返，再带料短闭环，最后整轮。
