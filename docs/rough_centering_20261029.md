# 粗加工2号工位对准画面中心

用户已明确目标：每次跑图在粗加工区粗停后，恢复固定观察姿态，由底盘微调，使2号圆环中心对准相机画面中心；停稳保持后再标定/执行机械动作。图像目标为`[width/2,height/2]`，不是此前手摆A点，不假设相机中心与夹爪中心重合。

## 已实现，尚未部署

在0.3.45候选交接上增加Pi自动循环，复用旧`AlignmentObserver`的编号、遮挡、置信度、五帧/500ms稳定判断与小步矩阵算法。停车后至少50ms才接受新采集帧；整组稳定帧都进入已验收像素容差才完成。默认拟合草稿为4像素，具体物理精度仍需量尺与放置验证。相机帧时间仍是主机读取完成时刻，不声称具有曝光时刻反馈。

运行顺序：固定观察姿态合同→PC0准备→显式选择的自动模式→停车后新帧→像素偏差→按实测矩阵选择单轴1～5mm→原Arrival/Exec执行→到位及零速批次完成→清空旧帧窗口重新观察→稳定对中→正常返回机构控制。最后只产生CENTERED结果，不发送使能轴、抓放、张爪、回零或机械目标；人工零点和持续PWM沿交接保持。最终复核统一了交接门槛：目标位置沿用已有手动1mm终点档，准备成功时冻结实际位置，后续相对该位置的漂移仍独立限制0.5mm；负目标、1.2mm残差和0.6mm保持漂移均拒绝，0.6mm已接受终点残差不再被重新收紧。

`vision/ring_feed.py`只向同一Pi的8092发固定GET，从原相机所有者取元数据，不再打开相机。HTTP、JSON文件保存由后台线程完成，串口线程不等HTTP或磁盘。相机新增`include_image=false`，自动控制不为每帧编码JPEG；原Web预览默认行为保持。元数据携带相机设备标识、视觉配置SHA、分辨率、采集服务ID和重连代次。

主机新增`vision/centering.py`；标定加载要求文件SHA、相机身份、观察姿态摘要、方向/量尺/重复性审查一致。浏览器不能提交像素偏差或矩阵来产生动作。相机重连、参数变化、错号、遮挡、过期、重复帧不能成为新动作依据。图像暂时不可用时保持已完成小步的停车状态，最多等待3秒，之后暂停；不会自动恢复或盲目追赶。原CAN故障、250ms反馈、失联停车、轴保持保护仍生效。

自动实验每轮最多12步、40mm、60秒；0.3.52起先按给定航向修正（±3°）转正车头，偏离超过3.2°、误差明显增大或连续两步不改善时暂停，允许用户检查后显式切回手动或结束。它们是本轮微调标定预算，不是正式整机任务的行程/速度限制。正式运行范围与效率需根据实测扩展，不能把尚未检验的更大范围写成已通过。

## 参数如何一次采集后复用

手动小位移前自动保留稳定2号环图像坐标、观察姿态摘要和odom；运动完成后重新取得停车后稳定观测，形成一条记录。每条包含命令、实际odom差分、前后中心、相机身份、启动会话、零点及动作ID，默认physical_reviewed=false。异步保存到设备核心runtime的`rough_centering_samples.json`，带整体SHA；重启恢复历史ID，损坏时保留原文件并禁止覆盖。Web显示最近记录ID，助手可直接读取文件，不要求用户抄一串机构数值。

离线`tools/fit_rough_centering.py`选择同一观察位的正负X/Y记录，求局部2×2逆矩阵。正反方向缺项、姿态/相机混用、非有限值、方向矛盾、航向变化过大、退化或拟合残差超过3像素均拒绝。优先使用有实际量尺且人工核对的位移，缺少量尺时仅按odom生成草稿。工具永不自动设置审核通过，也不覆盖旧文件。

实物验收后由助手整理审查参数，部署到runtime的`rough_centering_calibration.json`。该文件包含方向、量尺、重复性确认和相机/姿态SHA。Web的“读取已验收标定”只读取参数，不复位或烧录；自动按钮随后才可用。因此小位移试验后修改映射无需再次改固件或编译。新相机安装、观察姿态、分辨率或视觉配置变化会要求重新核对。

## 实物验收安排

1. 先经用户确认烧录0.3.45并做六节点、IMU、停车、PWM只读验收。当前真实板仍.44，候选没有部署或触发动作。
2. 用户确认本次现场后，在粗加工2号位粗停，恢复并保存一个独立的完整观察检查点（两轴、三舵机）；记录相机能稳定看到2号圆环的姿态。不能自动执行旧累计抓放表来获取观察位。
3. 手动标定模式按PC0准备一次，分别做+X5mm/−X5mm、+Y5mm/−Y5mm，等待每次停车后采样。用户只负责核对实际方向、尺量位移、线缆和干涉；助手读取记录拟合，必要时只补不足的记录。
4. 导入本车已验收矩阵，在已标定范围内从不同小偏差自动对到画面中心，至少三次独立回位；核对最终实物位置、像素偏差、动作数和耗时。实测前不能用合成矩阵代替本车矩阵，也不把像素容差直接叫毫米精度。
5. 微调稳定后冻结观察姿态和标定版本。用户再在这一固定到位基准上标定机械动作，夹爪与相机的偏置由机械目标吸收。抓放结束恢复同一观察姿态，再执行下一次对中。
