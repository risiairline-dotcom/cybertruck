# ZDT X42S 位置模式协议要点

依据《ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527》（`docs/assets` 未入库，原件在本机原工程）。手册描述型号协议，本车六台驱动的固件与参数仍需读回确认。来源：未合并分支 `codex/micro-position-experiment` 的离线整理。

| 页 | 内容 |
| --- | --- |
| 37 | Emm 位置命令同步标志 01 时只缓存；广播 `00 FF 66 6B` 触发所有有缓存的电机，示例每台返回 `FD 02` |
| 42–43 | CAN 扩展帧 ID、分包序号及回包格式 |
| 46 | 位置命令运行中可被新位置命令打断；未触发的缓存如何覆盖、清除未说明 |
| 57 | Emm `FD`：方向、整数 RPM、单字节加速度、32 位脉冲、模式（02 相对当前实时位置）、同步标志；3200 脉冲/圈为 1.8°、16 细分的默认例子 |
| 55–56 | X 固件 `FD` 字段格式不同 |
| 60 | `FE 98 00` 立即停止；手册未说明停止会清除同步缓存 |
| 98–106 | `42 6C` 读配置：Emm 返回 33 字节，X 返回 37 字节 |

## 未确认

- 非零地址 `FF` 是否只触发该节点；停止、失能、故障、掉线或重启是否清除同步缓存。
- `FD 02` 回包不带动作编号，无法区分迟到的旧回包。

同步广播会触发总线上所有有缓存的节点（含 ID5/6），上述问题确认前不用同步模式。小位移横移可先评估非同步相对位置（mode 02、sync 0）：四轮命令依次发出，起步差约为四次两帧发送时间，由驱动器内部完成加减速，代替现在的低速分段。
